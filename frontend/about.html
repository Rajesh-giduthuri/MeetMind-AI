ABOUT OUR PLATFORM

MEETMIND AI

MEETMIND AI is a meeting intelligence platform designed to help users organize meeting content and review important information in one convenient workspace. The interface brings meeting uploads, meeting links, analysis results, transcripts, summaries, and saved meeting records together in a structured experience.

What is MEETMIND AI?

A centralized workspace for managing and reviewing meeting information.

Meeting Input

Use the dashboard to select a supported meeting file or enter a meeting URL where that input type is supported by your application.

Meeting Insights

Review available meeting summaries, transcripts, and analysis results in the relevant result page when those features are configured and working.

Meeting Organization

Access your meetings and previously saved records through the Meetings and View History sections, according to the data available in your app.

USER GUIDE

How to Use MEETMIND AI

Follow these steps to navigate the website and use its main sections.

01

Open the Dashboard

Select Home from the sidebar. The dashboard provides the main starting point for submitting meeting content and accessing the application.

02

Select a Meeting Input

Choose a meeting file using the file selector, or enter a meeting URL in the URL field. Use only file formats and URL types supported by your current application.

03

Start Meeting Analysis

Click Analyze Meeting after providing the required input. Wait for the application to finish processing. Results depend on the analysis functionality configured in your app.

04

Review Meeting Results

When analysis is available, open the result page to review the transcript, summary, or other meeting information provided by your application.

05

Manage Your Meetings

Open Meetings to manage saved meeting records. Use View History to revisit earlier records that have been saved by the application.

06

Personalize Your Workspace

Visit Settings to manage available interface preferences, such as your display name, appearance, and other frontend options.

Helpful Tips

A few simple recommendations for a smoother experience.

  • Check that you have selected the correct file before starting an analysis.
  • Make sure a meeting URL is complete and belongs to a source supported by your application.
  • Keep important meeting information saved before leaving the page.
  • If analysis fails, check the message displayed by the application and verify that its required services are running.
  • Use the sidebar to navigate between the Dashboard, Meetings, View History, Settings, and About pages.
